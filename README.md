# Hackathon

Shared starting point for our hackathon. Fork this repo, create a branch, and start building.

## Get started

1. Click **Fork** at the top of this repository to create your own copy.
2. Clone your fork and create a branch:

   ```bash
   git clone https://github.com/YOUR-USERNAME/hackathon.git
   cd hackathon
   git switch -c feature/your-idea
   ```

3. Add your project files, then commit and push:

   ```bash
   git add .
   git commit -m "Start hackathon project"
   git push -u origin feature/your-idea
   ```

4. Open a pull request from your fork to this repository when you're ready to share your work.

Collaborators with write access can create and push branches directly in this repository.

Keep API keys, passwords, and local `.env` files out of commits. Share configuration through an `.env.example` file with placeholder values.
